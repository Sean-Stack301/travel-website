
🌍 Africa Travel Journey
A beautifully designed single-page travel website showcasing unforgettable adventures across Africa. Built with pure HTML and CSS, the website delivers a smooth, modern, and immersive experience across both desktop and mobile devices.

✨ Features
🌍 Modern Africa-inspired travel design

📱 Fully responsive for mobile, tablet, and desktop

⚡ Smooth scrolling and animations

🎨 Glassmorphism UI design

🖼️ Interactive travel gallery

🗺️ Travel timeline section

🚀 Lightweight single HTML file
